#Jujutsu Shenanigans Wiki
##A clean, high-performance, and Fandom-free encyclopedia for the Roblox battlegrounds game, Jujutsu Shenanigans.

###📘 About this Project
This wiki is a personal side project created to provide a streamlined experience for players. Unlike traditional platforms, this site is built with a specific philosophy:

* Fandom-Free: I am not a fan of the Fandom platform's layout and intrusive elements, so this wiki is hosted independently using MkDocs.

* Performance Focused: No trackers, no ads, no bloated scripts, and no auto-playing videos—just the data you need.

* Side Project: This is maintained in my spare time as a tribute to the game developed by Tze.

###🔗 Live Wiki
[View the Jujutsu Shenanigans Wiki here](https://vyzzze.github.io/jjs-wiki/)

###🛠️ Technical Stack
* Engine: MkDocs with the Material theme.

* Styling: Custom CSS for character "glow" effects and "fandom-style" table headers.

* Hosting: GitHub Pages.

###🗂️ Character Progress
Current characters documented include:

* Honored One (Gojo): Complete with base and awakening movesets.

* The Vessel (Itadori/Sukuna): Complete with base and King of Curses movesets.
